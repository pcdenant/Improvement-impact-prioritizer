Improvement Impact Prioritizer

Which action moves your P85 lead time the most? Describe the problem with your value stream data, attach each action to the stages it touches, and get a ranked list.

1 · THE PROBLEM

Where does the time go?

Value stream stages — median and P85 time spent in each stage (days).

StageMedianP85Avg WIP (items, optional)Source

One stage per line: Stage ⇥ Median ⇥ P85 ⇥ Source (optional). Copy the cells and paste. Replaces the current stages.

2 · THE ACTIONS

What does each action touch?

For each stage an action touches (upstream or downstream), estimate the time reduction in that stage: pessimistic / probable / optimistic, and the share of items affected. A negative % means the stage gets longer (e.g. more refinement time upstream).
WIP limit: if the stage has an average WIP, pick “WIP held” and enter the WIP the team will really hold (pessimistic / probable / optimistic, in items). By Little's law, at constant throughput, time in the stage drops in the same proportion as WIP. If the action also lowers throughput, the gain is overestimated.

One line per action, or per action × stage: Action ⇥ Stage ⇥ Pess % ⇥ Probable % ⇥ Optim % ⇥ % items. A line with only the action name adds the action without effects. Lines with the same action name are grouped. Adds to the current actions.

3 · THE IMPACT

Ranked by P85 gain (probable)

Bar = share of the gap to the target P85 that the action closes (probable). Full bar = target reached. Thin line = pessimistic → optimistic range. Tick actions to see their combined effect.

Your data stays in this browser (saved automatically). Nothing is sent anywhere.

How it works: each stage is modelled as a log-normal distribution fitted on its median and P85, and the total lead time is simulated (10,000 items). Each action is replayed on the same simulated items. The % gain on the simulated P85 is applied to your real P85, which corrects for the model's assumption that stages are independent. · Collaboration Solved
